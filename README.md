2. **📋 嚴格按照教學大綱章節順序排播（Strict Sequential Order）**
   - 徹底杜絕檔名亂序跳講與重複講次，從第 0 章 / 第 1 講循序推進。
   - 左側講次清單點選即可順暢換片，支援關鍵字即時模糊搜尋。

3. **📱 專為 iPhone 18 Pro 打造的行動瀏覽最佳化**
   - **吸頂視訊劇院（Sticky Top Video）**：直向持握下滑選課時，視訊固定置頂播放不中斷。
   - **單手大拇指切換**：[📋 本課講次] 與 [📚 全校 380 門課] 兩段式切換膠囊。
   - **雙擊快進快退**：點擊影片右半部 2 下快進 10 秒、左半部 2 下倒退 10 秒。
   - **動態島與安全區適配**：完美避開 Dynamic Island 藥丸挖孔與底部手勢列。
   - **零縮放輸入框**：解決 iOS Safari 點擊搜尋時螢幕被強制推近放大的問題。
   - **橫向自動切換**：橫握自動切換為左目錄、右視訊的雙欄劇院分鏡模式。
   - **鎖定畫面與耳機連動**：整合 Apple MediaSession API，支援鎖定畫面、AirPods 手勢切換講次與 AirPlay 投影。

4. **⚡ 雙核心串流驅動引擎**
   - **iOS / macOS Safari**：原生 Apple AVPlayer 硬體解碼 HLS，最省電、抗發燙、畫質最細膩。
   - **Windows Chrome / Edge / Firefox**：搭載輕量 Hls.js 引擎，支援自動故障重連。
